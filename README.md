Sizzle & Serve — run a tiny kitchen through the lunch rush: grab ingredients from the fridge, chop and fry them, build burgers on the plate, and serve each order before the customer walks out. Timed orders, combos, tips, a dinner rush, and a three-minute shift clock.

## How to play

- **Move** with WASD or the arrow keys. **E** (or a click) uses the station you are standing at; **M** mutes.
- **Fridge** — pick an ingredient (keys 1–6). Buns and cheese are ready to plate; patties need the stove, tomato, lettuce and onion need the chopping board.
- **Chopping board** — chops in a few seconds. **Stoves** — a patty cooks in about four seconds, but leave it too long and it burns.
- **Plating counter** — stack the recipe's ingredients on the plate, pick the plate up, and serve it at the **serve pass**. A plate must match an order exactly.
- Serve fast for a tip, and serve twice in a row for a combo multiplier. In the last minute the dinner rush hits: orders arrive faster and patience runs shorter.
- Five recipes: Classic Burger, Cheeseburger, Garden Stack, Double Trouble and Melty Onion Melt. The shift ends after three minutes — how much can you earn?

All art is drawn in code on a canvas and all sounds are synthesised with WebAudio. No external assets, no network requests, no libraries — just static files under `game/`.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
